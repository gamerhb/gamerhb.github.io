# Atharva Barad Portfolio — v2

A static multi-page portfolio for GitHub Pages.

## Structure
- `index.html` — recruiter-friendly homepage
- `about.html` — background, education, capabilities
- `experience.html` — complete experience timeline
- `projects.html` — full project archive + filters
- `articles.html` — writing index
- `projects/` — deep case studies
- `experience/` — deep experience case studies
- `articles/` — articles derived from project/experience decisions
- `Atharva_Barad_Resume.pdf` — current downloadable resume
- `assets/` — shared CSS/JS

## GitHub Pages

This repository is the user-site repository for the `gamerhb` GitHub account.

Publishing source:
- Branch: `main`
- Folder: `/ (root)`
- Default site URL: `https://gamerhb.github.io/`

## Public/private boundary
Do not make `gamerhb/System` or `gamerhb/career-hub` public just to support this portfolio.
The site describes private work without exposing private source code.
